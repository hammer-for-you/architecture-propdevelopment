## Требования к безопасности:
1. Шифрование трафика - любое обращение к партнёрскому API должно использовать HTTPS.

2. Шифрование данных приложения - необходимо шифровать персональные данные.

3. Управление доступом - должно быть разграничение доступа на основе ролей (RBAC).

4. Ограничение передачи персональных данных - персональные данные пользователей не должны передаваться стороннему сервису. Можно использовать токенизацию или анонимизацию.

5. Логирование действий пользователя - обращения к внешнему API партнёрской платформы должны логироваться с указанием времени, совершаемой операции и логина пользователя.

6. Сетевая изоляция - внешние подключаемые устройства (домофоны, шлагбаумы) должны находиться в отдельной DMZ-сети.

7. Защита от внешних атак - должна быть обеспечена защита от атак типа DDoS, так же должен проводиться регулярный аудит сетевой безопасности.

   
## Протоколы аутентификации и авторизации:
1. Работа с мобильным приложением - OAuth. 
   - Доступ к функциям мобильного приложения возможен только при наличии полученного от Keycloak токена.
   
   - Доступ к сервисам "Умного дома"  возможен только при наличии только при наличии полученного от Keycloak токена.
   
     
   
2. Взаимодействие с партнёрской платформой - API Key
   - Партнёрская платформа должна поддерживать механизмы аутентификации для использования API и предотвращать несанкционированный доступ к API при помощи механизма API Key.
   
     
## Взаимодействие между системами предприятия и внешней платформой:
- Партнёрская платформа предоставляет PropDevelopment API для взаимодействия с внешними устройствами "Умного дома".

- Весь обмен данными с партнёрской платформой должен осуществляться с использованием TLS.

- Работа с устройствами "Умного дома" должна регулироваться ролевой моделью. Например, "собственник", "жилец", "администратор".

- Партнёрская платформа должна поддерживать RBAC, используемый в PropDevelopment.

- Возможно использование API Gateway.
